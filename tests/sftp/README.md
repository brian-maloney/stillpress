# Test SFTP server

A throwaway OpenSSH server for the SFTP deployer's integration tests. Everything here is **test-only**: the
password and the key pairs exist only to log in to this container and must never be used anywhere else. The key pairs
are generated by `npm run sftp:start` into `tests/sftp/.keys/`, which git ignores, so no private key is ever committed.

```bash
npm run sftp:start   # builds the image and joins it to the wp-env network as sftp.test
npm run sftp:stop
```

- User `deploy`, password `deploy-test-password`.
- `deploy_key` (no passphrase) and `deploy_key_encrypted` (passphrase `test-passphrase`) are authorized.
- `/home/deploy/www` is writable; `/home/deploy/readonly` is not.

Tests that need it skip themselves when `sftp.test:22` isn't reachable.
